VGC Tactics Studio — Light/Dark + Logo + Item Icons

MỞ WEBSITE:
  Mở index.html với Live Server trong VS Code (hoặc trực tiếp qua trình duyệt có kết nối Internet).

TÍNH NĂNG MỚI:
  - Nút Sáng/Tối trên thanh trên cùng, lưu lựa chọn vào localStorage.
  - Logo SVG mới hiển thị cả trên header và tab trình duyệt (favicon).
  - Item Picker có ảnh, tìm kiếm và danh sách riêng cho vật phẩm/Mega Stone.
  - Giữ danh sách Item hợp lệ M-C từ bản dự án trước.
  - Icon vật phẩm thông thường tải từ Pokémon Showdown khi có Internet.
  - Mega Stone chưa có sprite riêng dùng icon tinh thể mẫu, Item không có ảnh dùng icon dự phòng.

FILE:
  index.html, app.js, data.js, style.css, assets/*.svg

KHẮC PHỤC CACHE:
  Ctrl + F5 trong trình duyệt.

Lưu ý: bản cập nhật này chỉ chỉnh giao diện, không thay đổi công thức damage.
